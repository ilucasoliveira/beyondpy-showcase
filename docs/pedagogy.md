# Pedagogy

BeyondPy is built on one idea: **learning is demonstrating, not consuming**. Every screen follows from
a short list of principles.

## The principles

1. **Every lesson ends in graded practice.** Reading is not the goal; doing is.
2. **Read and predict before writing.** Each lesson asks the student to predict an output before
   running it.
3. **Strong support first, removed little by little.** A guided exercise with blanks (`___`) comes
   before an independent one, and hints come in steps.
4. **Retrieve and space, without punishment.** Spaced review with a daily limit.
5. **Feedback that says the next action**, not just "wrong".
6. **A predictable structure and a visible goal** (the 12 blocks below).
7. **Coming back is part of studying.** The site always shows where you left off and the next step.
8. **Literal language and WCAG 2.2 AA accessibility.**
9. **The student controls stimuli and pace:** theme, font size, reduced motion, the mascot.
10. **No rankings, timers or lost points.** The one exception is the streak, softened by 3 hearts a
    month that cover a missed day on their own.
11. **Progress from real evidence** (lessons opened, exercises solved, reviews done), never an
    invented "mastery" percentage.
12. **AI, where it appears, protects learning:** no solution before an attempt.

## The 12 blocks

Every lesson has the same sections, in the same order:

| # | Block | Purpose |
|---:|---|---|
| 1 | Goal | What you can do at the end |
| 2 | Prerequisites | What you need first, with links |
| 3 | Real-world situation | A real problem, something working in 2 to 5 minutes |
| 4 | Explanation | Short blocks, one idea each |
| 5 | Minimal example | The smallest code that shows the idea |
| 6 | Key points | Usually a table |
| 7 | Prediction question | Predict the output before running |
| 8 | Guided exercise | With blanks and hints |
| 9 | Independent exercise | No blanks |
| 10 | Feedback | How the grader answers and what to check |
| 11 | Summary | The lesson in a few lines |
| 12 | Next review and connections | When it comes back and where it leads |

On screen, the 12 blocks are grouped into 5 steps, so a lesson feels short.

## Spaced review

Opening a lesson schedules its review cards. The first review is the next day; each correct answer
grows the interval (1, 3, 7, 14, 30, 60, 120 and 240 days), and a miss sends the card back to one day.
A daily limit (10 cards by default) keeps the queue from turning into homework, and the cards from the
newest lessons come first.

## Feedback that teaches

Each test has a name the student reads ("Grade 6, the limit: Passed") and, when it fails, a message
that points to the next action. Hints open one at a time, and the reference solution appears only
after the exercise is solved, sometimes with a short note on why it works and which alternatives also
pass.

## BeePy, the mascot

BeePy is a friendly Python who lives in the corner of every page. He greets, celebrates a passed
exercise, offers a hint when tests fail and, after a few days away, sums up the last lesson so coming
back is easy. Anyone can shrink or hide him in the settings.
